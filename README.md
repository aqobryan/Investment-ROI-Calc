# Investment ROI Calculator

A Python tool to calculate investment returns, find required CAGR growth targets, and project future values using live stock market data via Yahoo Finance.

## Features
- **Forward Growth Projection:** Calculate future portfolio value based on an expected annual return rate.
- **Target Goal Mode:** Determine the exact required Compound Annual Growth Rate (CAGR) needed to hit a specific dollar target.
- **Live Stock Ticker CAGR:** Fetch real historical stock performance for symbols like `AAPL`, `MSFT`, or `SPY` to project future returns.
